# CropGuard AI — Crop Disease Detection with Grad-CAM

> AI project | 2 members max | Present: May 18

---

## What this project does

Upload a photo of a crop leaf → the AI:
1. Detects which disease is present (38 disease classes)
2. Tells you the confidence level
3. Generates a **Grad-CAM heatmap** showing exactly WHERE on the leaf it detected the disease
4. Estimates severity (Mild / Moderate / Severe)
5. Recommends a treatment

## Setup (step by step)

### Step 1 — Install Python packages

```bash
pip install -r requirements.txt
```

### Step 2 — Download the PlantVillage dataset

Go to Kaggle and download:
https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset

Unzip it. You should have a folder like:
```
PlantVillage/
    Apple___Apple_scab/        (images)
    Apple___Black_rot/         (images)
    Apple___healthy/           (images)
    Tomato___Bacterial_spot/   (images)
    ...  (38 folders total)
```

Put the `PlantVillage/` folder in the same directory as `train.py`.

### Step 3 — Train the model

```bash
python train.py
```

This will:
- Run for ~15–30 minutes depending on your GPU/CPU
- Save `crop_disease_model.h5`
- Save `class_indices.json`
- Save `training_curves.png`

Expected accuracy: **92–96%** on the validation set.

### Step 4 — Run the demo app

```bash
streamlit run app.py
```

Open your browser at `http://localhost:8501`

Upload any leaf photo and see the result!

## How Grad-CAM works (for your presentation)

Grad-CAM = **Gradient-weighted Class Activation Mapping**

1. Feed the image through the CNN
2. Record which neurons fired strongly in the last conv layer
3. Compute how much each neuron's activation affected the final prediction
4. Create a heatmap: hot colours (red/yellow) = regions that caused the prediction
5. Overlay heatmap on the original image

**Why it impresses your teacher:**
- The model doesn't just say "this is tomato blight" — it *shows you* where the blight is
- It makes the AI transparent and trustworthy
- It's used in real medical AI systems (e.g., detecting cancer in X-rays)
